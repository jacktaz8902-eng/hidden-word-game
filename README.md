# 히든 워드 (숨은 단어 맞히기)

워크숍 팀빌딩용 단어 유사도 추리 게임입니다. 방장이 방을 만들고 초대 링크를 보내면, 링크로 들어온 사람끼리 각자 폰에서 함께 진행합니다(최대 8명/팀).

- 연결: PeerJS(P2P). 방장 브라우저가 게임을 관리합니다. 서버·API 키가 필요 없습니다.
- 문제 단어: 일상 명사 972개 (`pool.json`), 봉투마다 5개씩 무작위.
- 힌트 사전: 일반명사·고유명사 226,088개 (`words.txt`). fastText 한국어 벡터 상위 100만 단어 중 명사만 추렸습니다.
- 유사도: 문제 단어마다 힌트 사전 전체와의 유사도(0~100)를 미리 계산해 `s/<번호>.bin.gz`에 저장했습니다. 방장은 출제자 차례마다 점수표 1개(약 130KB)만 내려받습니다.

단어 벡터 출처: fastText Common Crawl 벡터 (Grave et al., 2018), CC BY-SA 3.0. 형태소 분석: Kiwi.
